# Обновление расширения FCRM

В папке расширения лежат `update.bat` и `update.ps1`. Для обновления запустите `update.bat`, после завершения перезагрузите расширение на странице `chrome://extensions` и обновите страницу Jira. Пользовательские настройки Chrome при этом сохраняются.

Начиная с версии 3.5.184 дашборд проверяет номер установленной версии при открытии. Если на GitHub вышла новая сборка, под вкладками появится уведомление «Как обновить» с инструкцией и ссылкой на ZIP. В открытой вкладке проверка повторяется раз в 10 минут.

Обновление скачивает `FCRM-Chrome-3.3.zip` из ветки `main` репозитория `V-M221/jira-fcrm`. Сначала архив проверяется целиком; если загрузка или проверка не прошла, установленные файлы остаются прежними. Если при замене возникла ошибка, программа пытается восстановить исходные файлы.

## Публикация новой сборки

1. Выполните `npm run build:extension`. Команда пересобирает папку `FCRM-Chrome-3.3` и одноимённый ZIP, включая файлы обновления, и записывает версию сборки в `extension-version.json`.
2. Проверьте содержимое ZIP перед публикацией: репозиторий публичный. Не включайте в него реальные задачи, персональные данные или секреты.
3. Опубликуйте `FCRM-Chrome-3.3.zip` и созданный вместе с ним `extension-version.json` одним коммитом в корне ветки `main`. Из ZIP пользователи получат сборку, а из JSON расширение прочитает её версию.

Если меняется сам механизм обновления, пользователям необходимо отдельно заменить `update.bat` и `update.ps1`: запущенный скрипт не заменяет себя при обновлении.
